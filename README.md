# Folio

A Canva-style document studio that runs entirely in the browser.

- Templates for resumes, posters, invitations, slides, stories, and letterhead
- Drag, resize, snap-to-guides, in-place typing
- Type, shapes, photos, page backgrounds, layers, undo/redo
- Export PNG or multi-page PDF
- Autosave to `localStorage` — nothing is uploaded

```bash
npm install
npm run dev
```
